This folder is where your background music goes.

To add "our song":
1. Get an MP3 file you have the rights to use (your own recording,
   a royalty-free track, or a song you've licensed).
2. Rename it exactly to: our-song.mp3
3. Drop it in this folder (public path becomes /audio/our-song.mp3).
4. Commit + push + redeploy.

The play/pause button in the top-right corner already points at
audio/our-song.mp3 — it just needs the file to exist. Until then,
the button will simply toggle silently without throwing an error.
